# 1Fi Marketplace - SDE Intern Assignment

A mobile application feature built with **React Native** and **Expo** that implements the **1Fi Marketplace** tab within the existing 1Fi Shop page architecture.

---

## 📱 Feature Overview

The application features a 3-tab segment navigation system on the Shop page:
1. **Top Brands** – Unimplemented (Blank placeholder page as per guidelines).
2. **Nearby Stores** – Unimplemented (Blank placeholder page as per guidelines).
3. **1Fi Marketplace** – Fully functional interactive marketplace allowing users to browse dynamic credit/financing products, select product variants, choose EMI tenure plans, and view dynamically updating CTAs.

---

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v16.0.0 or higher)
- **npm** or **yarn**
- **Expo Go** mobile app (available on Google Play Store for physical device preview) or **Android Studio Emulator**

### Installation

1. **Clone the repository:**
   ```
   git clone https://github.com/YOUR_USERNAME/1fi-marketplace.git
   cd 1fi-marketplace
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Start the development server:**
   ```
   npx expo start
   ```

4. **Run on target environment:**
   - **Android Device:** Scan the displayed QR code using the **Expo Go** app.
   - **Web Browser:** Press `w` in the terminal to view in browser.
   - **Android Emulator:** Press `a` in the terminal (requires Android Studio).
